
##  Структура проекта

```text
├── public/                  # Статические файлы, доступные напрямую
│   └── assets/              # Шрифты, звуки, фавиконки и внешние ассеты
├── src/
│   ├── assets/              # Внутренние медиа-ресурсы
│   │   ├── icons/           # Иконки интерфейса
│   │   └── images/          # Изображения, фоны, спрайты
│   ├── components/          # Переиспользуемые UI компоненты (кнопки, модалки, карточки)
│   ├── games/               # Модули отдельных игр (каждая игра в отдельной подпапке)
│   ├── hooks/               # Кастомные хуки (useTelegram, useAudio, useStorage и др.)
│   ├── pages/               # Страницы/экраны приложения (Каталог/Лобби, Игра, Профиль, Лидерборд)
│   ├── services/            # Интеграция с API, Telegram CloudStorage, аналитика
│   ├── styles/              # Глобальные стили, темы Telegram (tg-theme-*)
│   ├── types/               # TypeScript типы и декларации (Telegram WebApp, Game, User)
│   └── utils/               # Вспомогательные функции и хелперы
├── .env.example             # Шаблон переменных окружения
├── .gitignore               # Исключения для Git
└── README.md                # Документация проекта
```
